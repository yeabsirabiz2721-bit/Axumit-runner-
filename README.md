 🎮 Axumit Runner
Axumit Runner is a simple fast-paced browser game where you dodge falling obstacles and try to survive as long as possible 
 🚀 Play the game
If deployed, you can play it here:  
https://your-game-link.onrender.com
🎯 How to play
- Use Left Arrow and Right Arrow to move  
- Avoid the falling red blocks  
- Survive as long as possible  
- Try to get the highest score
